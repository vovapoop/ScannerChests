# Chest Scanner

Распознавание сундуков Minecraft по скриншоту экрана: сканирование открытого сундука,
определение предметов и количества, ведение базы предметов, история сканирований,
экспорт в CSV/JSON и отправка отчётов в Discord.

## Возможности

- Сканирование открытого сундука (автоскан по таймеру или по горячей клавише).
- Распознавание предметов по иконкам (SSIM + цветовые гистограммы) и количества по шаблонам цифр.
- Автоматическое добавление неизвестных предметов в базу.
- База предметов: категории, теги, алиасы, несколько фото, размер стака.
- История сканирований с фильтрами и сравнением двух сканов.
- Экспорт: полная выгрузка CSV/JSON, сводная таблица CSV.
- Отправка отчётов в Discord через webhook (создание/редактирование/удаление сообщений).
- Профили: у каждого своя база предметов, настройки и результаты.
- Калибровка сетки и отладка распознавания встроенными инструментами.

## Требования

- Windows 10/11.
- Для запуска готового **exe** Python не нужен (см. «Установка и запуск»).
- Python 3.10+ (с пунктом *Add python.exe to PATH*) нужен только для запуска
  из исходников и для сборки exe.

Установка зависимостей выполняется автоматически (`start.bat` или `build.bat`).

## Установка и запуск

### Готовый exe (без Python) — рекомендуется

Устанавливать Python не нужно:

- **Установщик.** Запустите `ChestScannerSetup.exe` — установка в
  `%LocalAppData%\Programs\ChestScanner` (ярлыки и деинсталлятор создаются автоматически).
- **Портатив.** Распакуйте `ChestScanner-portable.zip` в любую папку
  и запустите `ChestScanner.exe`.

> При первом запуске Windows запросит **права администратора** (UAC) — они нужны
> для глобальных горячих клавиш (библиотека `keyboard`). Разрешите запрос: exe-сборка
> запрашивает права автоматически через манифест.

При первом запуске начнётся мастер настройки: имя профиля и Discord webhook (можно пропустить).

### Из исходников (Python 3.10+)

1. Скачайте проект и распакуйте его в удобную папку.
2. Дважды кликните по **`start.bat`**.
3. Скрипт самостоятельно создаст виртуальное окружение `.venv`, установит зависимости
   из `requirements.txt` и запустит приложение (окно «Chest Scanner»).

### Запуск вручную

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install --no-cache-dir -r requirements.txt
.venv\Scripts\python.exe main.py
```

### Запуск из VS Code

Откройте папку проекта, файл `main.py` и запустите его (кнопка Run или `python main.py`).

## Первый запуск

1. Мастер настройки: укажите имя профиля (например, «Основной») и, при желании, Discord webhook.
2. Откройте сундук в игре (интерфейс инвентаря сундука должен быть на экране).
3. Нажмите **F8** — программа отсканирует содержимое.

Если сундук не распознаётся — выполните калибровку сетки («Калибровка» в панели инструментов)
и при необходимости «Шаблоны (авто)» для генерации шаблона сундука и пустого слота.

## Горячие клавиши

По умолчанию:

| Клавиша | Действие |
|---|---|
| F6 | Отладка цифр |
| F7 | Отладка сетки |
| F8 | Сканирование сундука |
| F9 | Отправка в Discord |
| F10 | Выход |

Клавиши настраиваются в **Настройки → Основные → Горячие клавиши**
(имена клавиш как в библиотеке `keyboard`: `f1`–`f12`, цифры, буквы). Пустое поле отключает
действие. Изменения применяются сразу после «Сохранить», без перезапуска.

> Горячие клавиши работают только с правами администратора (ограничение библиотеки
> `keyboard` в Windows). В exe-сборке права запрашиваются автоматически при запуске (UAC),
> при запуске из исходников запускайте от имени администратора вручную.

## Discord

Для отправки отчётов нужен webhook канала:

- **Вариант 1.** Укажите URL в настройках («Настройки → Discord») — сохраняется в файл
  `discord_webhook.json` профиля.
- **Вариант 2.** Задайте переменную окружения `DISCORD_WEBHOOK_URL` (имя переменной можно
  изменить в настройках).

Формат сообщения и таблицы настраивается в `config.json` (блок `discord_message`).

## Данные и структура проекта

| Путь | Назначение |
|---|---|
| `main.py` | Точка входа: бутстрап `.venv` и запуск GUI |
| `start.bat` | Автосоздание `.venv`, установка зависимостей, запуск без консоли |
| `build.bat` | Сборка автономного exe (`dist/`) |
| `ChestScanner.spec` | Конфиг PyInstaller (onedir, без консоли, UAC-админ) |
| `installer.iss` | Установщик Inno Setup (`ChestScannerSetup.exe`) |
| `version_info.txt` | Версия и метаданные exe |
| `requirements.txt` | Зависимости (диапазоны версий) |
| `config.json` | Настройки активного профиля (Default) |
| `items.json` | База предметов активного профиля (Default) |
| `items/` | Изображения предметов профиля |
| `results/chests.json` | Результаты сканирований |
| `results/history/` | Архивные отчёты |
| `unknown_items/` | Иконки нераспознанных предметов |
| `logs/scanner.log` | Журнал приложения (ротация) |
| `profiles/` | Данные остальных профилей |
| `assets/` | Шаблоны сундука, пустого слота, цифр, иконки предметов |

### Модули

- `chest_scanner/app_bootstrap.py` — окружение, DPI-awareness, импорт зависимостей.
- `chest_scanner/gui/` — интерфейс (core — окно и цикл, settings — настройки,
  dialogs — диалоги, widgets — переиспользуемые виджеты).
- `chest_scanner/scanner/` — логика сканера (base, detection, grid, items, ocr,
  workflow, discord).
- `chest_scanner/config.py`, `paths.py` — конфигурация, профили, пути по умолчанию.
- `chest_scanner/export.py` — экспорт CSV/JSON.

## Устранение неполадок

| Проблема | Решение |
|---|---|
| Окно закрылось сразу после запуска | Смотрите `startup_error.log` и `venv_setup.log` в корне проекта |
| `.venv` не создаётся | Установите Python 3.10+ и добавьте его в PATH |
| Горячие клавиши не работают | exe-сборка запрашивает админа сама (UAC); из исходников запускайте от имени администратора |
| Предметы не распознаются | Обновите базу предметов в «Предметы»; проверьте пороги в «Настройки → Распознавание» |
| Сетка не совпадает с сундуком | Выполните «Калибровку»; при смене масштаба Windows перекалибруйте |
| После переезда на другой ПК | Удалите папку `.venv` и запустите `start.bat` заново |
| exe не запускается / «неизвестный издатель» | Проверьте блокировку SmartScreen; смотрите `logs\scanner.log` рядом с exe |
| Свежий exe блокируется антивирусом | Ложные срабатывания возможны у PyInstaller-сборок: добавьте папку в исключения или пересоберите |
| Нужен Python для работы exe | Не нужен — автономная сборка содержит интерпретатор внутри |
| Настройки «поплыли» | «Сброс настроек» в панели инструментов (старый конфиг сохранится в `.backup`) |
